doku.md is a fast, native desktop app for browsing, searching, and understanding Markdown documentation — built for developers who live in specs, plans, and tasks.

Built for reading, not editing

Everything you need to recover context

⌘

Full-text search

SQLite FTS5 indexes every Markdown file the moment you open a project. Search by title, path, or content — results in under a second, even across thousands of files.

⟲

Live sync

A file watcher keeps the index up to date automatically. Create, edit, move, or delete files — doku.md reflects the change within seconds, no restart needed.

▤

Three-column reading

Navigation, document, and table of contents — side by side. Tabs for multi-document workflows, bookmarks for quick access to what matters most.

⌗

Spec-aware

Built by someone who lives in spec.md, plan.md, and tasks.md every day. doku.md understands the structure that AI-assisted development produces.

⊞

Plugin system soon

Detect project structures — Spec Kit, OpenSpec, ADRs, changelogs — and surface them with custom views. Planned for a future release.

○

Works offline

No account, no cloud, no telemetry. Everything runs locally — your documentation never leaves your machine. Semantic search via local AI is planned for a future release soon.
