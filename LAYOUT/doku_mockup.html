Feature Specification: Markdown Documentation Browser

specs/001-markdown-doc-browser · 2026-06-10 · Draft

Overview

Desktop application for browsing, searching, and understanding Markdown-based technical documentation. Helps developers recover context from projects where documentation is spread across multiple files and folders.

User Stories

The core experience is opening a project folder and navigating its documentation through a file tree. Search is the second pillar — finding information quickly when browsing isn't enough.

Technical Stack

const  stack = {
  backend:  'Wails3 + Go 1.22',
  frontend: 'Svelte 5 + TypeScript',
  storage:  'SQLite + FTS5',
  watcher:  'fsnotify',
}  // one database per project

Success Criteria

Open a project with 1000 files in under 5s. Full-text search returns results in under 1s. File changes reflected within 3s. Memory usage under 200MB at scale.
